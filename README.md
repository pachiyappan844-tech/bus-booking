# Bus Booking System

A console-based Online Bus Ticket Booking Application built using Java, JDBC and MySQL.

## Tech Stack
- **Java** - Core application logic
- **JDBC** - Database connectivity  
- **MySQL** - Database to store bus and booking details

## Features
- View Available Buses with Timings and Seats
- Book Tickets by Selecting Bus ID and Seat Count
- Automatic Seat Availability Update
- Store Passenger and Booking Details in Database

## How to Run This Project
1. Execute `bus.sql` file in MySQL to create database and tables
2. Update your MySQL username and password in `DBConnection.java`
3. Compile the code: `javac BusBookingSystem.java`
4. Run the application: `java BusBookingSystem`
